# Фото One — iPhone-приложение для быстрой коррекции фото

MVP нативного приложения: **один тап — готово**. Вся обработка на устройстве
(без серверов, аккаунтов и подписок), поэтому приложение работает офлайн и не
зависит от блокировок.

Требования к устройству: **iPhone с iOS 17+**.

## Что уже есть

| Инструмент | Поведение |
|---|---|
| **Авто** | Экспозиция, контраст, баланс белого подбираются по снимку (`autoAdjustmentFilters`) |
| **Свет** | Яркость, контраст, насыщенность, тепло — слайдеры |
| **Фон** | Боке / затемнение / ч-б / замена цветом. Обрабатывается **только фон**, передний план остаётся пиксель в пиксель (`VNGenerateForegroundInstanceMaskRequest`) |
| **Портрет** | Смягчение кожи только в области лица (`VNDetectFaceRectanglesRequest`) |
| **Фильтры** | Vivid, тёплый, холодный, ч-б, Fade, Noir, Chrome |
| **Кадр** | 1:1, 4:5, 16:9 по центру |
| **До/после** | Удержание пальца на превью |
| **Экспорт** | Share sheet: сохранить в «Фото», отправить, AirDrop. Рендер до 4096 px по длинной стороне |

Размер приложения — единицы мегабайт, сторонних зависимостей нет.

## Структура

```
project.yml                      # спецификация XcodeGen (генерирует .xcodeproj)
Config/Info.plist                # Info.plist (вне папки исходников — так надёжнее)
PhotoOne/
  App.swift
  Models/EditState.swift         # состояние редактирования
  Engine/PhotoEngine.swift       # Core Image + Vision: маски, фон, цвет, кроп
  Engine/Extensions.swift        # нормализация ориентации, hex-цвета
  ViewModels/EditorViewModel.swift
  Views/EditorView.swift         # экран редактора
  Views/Components.swift         # чипы, слайдеры, share sheet
  Assets.xcassets/               # иконка
.github/workflows/build-ipa.yml  # сборка .ipa на macOS-раннере GitHub
```

## Сборка `.ipa` без Mac

1. Залей содержимое этой папки в **публичный** репозиторий GitHub (ветка `main`).
2. Открой вкладку **Actions → Build unsigned IPA → Run workflow**
   (или просто сделай пуш — сборка стартует сама).
3. Через ~4–6 минут скачай артефакт **PhotoOne-unsigned** → внутри
   `PhotoOne-unsigned.ipa`.

Сборка идёт без подписи (`CODE_SIGNING_ALLOWED=NO`), подписывать будем на ПК.

## Установка на iPhone через Sideloadly (Windows)

1. Скачай [Sideloadly](https://sideloadly.io) и установи.
2. Подключи iPhone кабелем, нажми «Доверять этому компьютеру».
3. Перетащи `PhotoOne-unsigned.ipa` в окно Sideloadly.
4. Введи свой **Apple ID** и пароль (это обычная подпись разработчика Apple,
   данные идут только на серверы Apple; пароль приложения не нужен).
5. Нажми **Start**. После установки: **Настройки → Основные → VPN и управление
   устройством → Доверять разработчику**.

Ограничения бесплатного Apple ID: приложение живёт **7 дней**, максимум 3
приложения, нужна переподпись. Sideloadly умеет переподписывать по Wi-Fi
автоматически («Refresh via Wi-Fi»). Платный Apple Developer ($99/год) снимает
эти ограничения — подпись на год.

## Локальная сборка (если есть Mac)

```bash
brew install xcodegen
xcodegen generate
open PhotoOne.xcodeproj      # Run на подключённом iPhone
```

Bundle ID по умолчанию — `com.photoone.app`. Он уникален только в рамках твоей
команды, для сайдлоада менять не нужно.

## Известные ограничения MVP

- Портретное смягчение работает по прямоугольнику лица, без разметки глаз и губ:
  на высокой интенсивности возможен «пластиковый» эффект.
- «Фон» требует явного переднего плана на снимке; для пейзажа маска может не
  найтись — приложение честно сообщает об этом.
- Кроп только центральный, без ручного перемещения рамки.
